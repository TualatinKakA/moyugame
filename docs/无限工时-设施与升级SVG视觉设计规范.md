# 《无限工时》设施与升级 SVG 视觉设计规范

## 1. 已确认的核心规则：一设施，一图案

设施与它的 23 档升级共用完全相同的主体图案。主体负责识别设施，右上角徽章只负责识别升级段数。

- 设施本体：无徽章。
- 第一段升级：相同主体＋铜色数字 `1`。
- 第二段升级：相同主体＋银色数字 `2`。
- 第三段升级：相同主体＋金色数字 `3`。
- 第 4～23 段升级：相同主体＋对应实际数字，徽章颜色由金色等步长过渡至紫色；第 23 段为紫色。

24 张图的主体路径、颜色、尺寸、位置和透视必须一致。不得为不同升级分别更换道具，也不得通过水印、底部刻度、外框或主体改色表达档位。

数字是主要信息，金属色与金紫色阶是辅助信息。即使灰度显示，仍可直接读出实际档位。

## 2. 视觉风格：低多边形职场物件

图标向项目现有 PNG 靠拢，而不是另起一套徽章式线稿：

- 透明背景，主体直接呈现，无卡片底和装饰外框。
- 无描边，用不同明暗的实心多边形表现正面、侧面、顶面和厚度。
- 使用轻微透视与克制块面，不追求真实纹理、照片感或复杂细节。
- 主色为灰白、灰黑和棕色，少量橙色作为企业标识或功能强调。
- 禁用无限符号、发光、滤镜、复杂渐变和额外装饰轨道。
- 原始 Farm／Cathedral 等英文名只用于稳定 ID；图形采用现代职场和组织尺度语义。

## 3. 画布、颜色与徽章参数

| 项目 | 规范 |
| --- | --- |
| 画布 | `64 × 64`，`viewBox="0 0 64 64"` |
| 主体安全区 | 通常限制在 `4～60`，主体尽量保持一致的视觉面积 |
| 背景 | 透明 |
| 深色结构 | `#333B3A`、`#46504F` |
| 中间灰 | `#697473`、`#899492`、`#AAB8B8` |
| 浅色结构 | `#D9E2E2`、`#EEF3F2` |
| 棕色主体 | `#A5684A`、`#835039`、`#65402F` |
| 功能强调 | `#C4764D`、`#DF9A6C` |
| 自动化辅助色 | `#91B77A`、`#B4CDA3` |

升级徽章固定在右上角，使用相同切角轮廓和矢量数字路径，不依赖系统字体。双位数徽章可以向左扩展，但右缘、高度和切角语言保持一致。

| 段数 | 主色 | 顶面高光 | 底面暗部 |
| --- | --- | --- | --- |
| 1 | `#B97852` | `#D49A73` | `#8E563C` |
| 2 | `#C3CECE` | `#EEF3F2` | `#8E9C9C` |
| 3 | `#E7CA74` | `#F5E4A8` | `#B09552` |
| 4～22 | 按下方公式等分插值 | 按下方公式等分插值 | 按下方公式等分插值 |
| 23 | `#A875D8` | `#D3B9EF` | `#74509A` |

第 4～23 段使用离散纯色，不使用 SVG 渐变元素。令 `t = (N - 3) / 20`，在 sRGB 各通道分别线性插值并四舍五入为整数：

- 主色：`#E7CA74 → #A875D8`。
- 顶面高光：`#F5E4A8 → #D3B9EF`。
- 底面暗部：`#B09552 → #74509A`。

数字统一使用 `#252A27`。徽章可以覆盖主体的右上角局部，但不能改变主体本身。

## 5. 文件与生成约定

```text
assets/images/content-icons/
├── buildings/<building-id>.svg
└── upgrades/<building-id>-tier<1|2|…|23>.svg
├── preview.html
└── preview.png
```

文件名使用内容定义中的稳定 ID。当前覆盖范围为 17 个设施、391 个设施升级，共 408 张 SVG；不包含部门升级、通用升级、法术或奖杯。

制作与修改要求：

1. 先完成并确认设施本体，再由该文件的主体 `<g>` 生成 23 档升级。
2. 每档升级只能追加对应的 `upgrade-tier-1`～`upgrade-tier-23` 徽章组。
3. 修改设施造型时，必须重新生成对应全部 23 档升级，禁止只改其中一张。
4. 每张 SVG 自带 `<title>` 与 `<desc>`，说明设施和实际段数。
5. 只使用内联矢量图形，不引用字体、CSS、脚本、外部位图或其他 SVG。
6. 不使用动画、滤镜或渐变元素，避免大量卡片同时渲染时产生额外开销。

## 6. 验收清单

- 文件数量与 `BUILDING_DEFINITIONS`／`BUILDING_UPGRADE_DEFINITIONS` 一致。
- 逐组比较主体 `<g>`，确保 23 档升级与设施本体逐字符一致。
- 每张升级只有对应实际段数的徽章，无漏图、错号、错色或跳档。
- 第 4～23 段逐档校验等步长插值颜色；第 3 段必须为金色，第 23 段必须为紫色。
- 浏览器实际加载全部 SVG，检查 `naturalWidth`，不能只检查文件存在。
- 同时检查大图和 32px 实尺寸；重点确认物件轮廓和右上角单位数／双位数仍可辨认。
- 检查无 404、浏览器脚本错误、外部资源、动画、滤镜和渐变元素。
- 全量评审入口为 `assets/images/content-icons/preview.html`，静态总览为 `preview.png`。
