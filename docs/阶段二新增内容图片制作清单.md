# 阶段二新增内容图片制作清单

> 范围：仅列阶段二新增、当前共用 `assets/images/content-icons/red-cross.svg` 的内容。已有独立图标的旧内容不重复列入。
>
> 数量：**112 个内容条目＋1 个衍生合集图标**。当前全部为待制作状态。

## 资源路径约定

制作完成后，将各定义中的 `ui.icon` 从红色大叉替换为对应资源；Hall 合集另改 `ui.collectionIcon`。

| 分类 | 建议路径 |
| --- | --- |
| 设施本体 | `assets/images/content-icons/buildings/<条目ID>.svg` |
| 设施升级／Hall Bonus／合集 | `assets/images/content-icons/upgrades/<条目ID>.svg` |
| 部门条约、普通升级、协议、传承、同名升级 | `assets/images/content-icons/factions/<条目ID>.svg` |
| Royal Exchange | `assets/images/content-icons/exchange/<条目ID>.svg` |
| 法术 | `assets/images/content-icons/spells/<条目ID>.svg` |
| 奖杯（成就） | `assets/images/content-icons/trophies/<条目ID>.svg` |

同一 ID 在表内只代表一个内容条目；同名法术 Trophy 与其 Upgrade 是两个不同条目，需要分别配置图片，但可复用同一美术资源。
