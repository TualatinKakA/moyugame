# 无限工时 v1.1.2 Patch Notes

## 期权激励与职业增益

- 修复未购买“期权激励”时，R1 的“每份期权 +0.2% 产出”仍然独立生效的问题。未购买时期权产出倍率为 ×1。
- 同期权相关的影响力发现率也改为仅在持有“期权激励”后生效；退休清除本轮购买后，两项效果都会关闭。
- 按原版 4.3.24 build 26618872 恢复设施期权产出公式：A0–A3 为 `1 + 0.01 × (有效期权数 × 每份加成)^0.9`，A4 为 `1 + 0.01 × 有效期权数 × 每份加成`，不再在全部阶段使用线性公式。
- 购买“期权激励”后，每份基础加成为 2%，R1 额外提供 0.2%，即 R1 每份合计 2.2%；三项 Gem Upgrade、FR7、AN8 和 GB8 继续按各自加算或乘算接口组合。
- 修复数字员工错误乘入设施全局倍率的问题。R1 全局与时间产出、Exchange、Call to Arms 和期权倍率不再直接放大员工；员工只使用搬砖收入、5% 基础比例和员工专属增益。
- 修复 EL2／FR5／Treasure 路径的重复叠算：设施产出仍可先加入基础搬砖收入再影响员工，但不再被同一全局倍率额外乘第二次。
- R1 职业增益卡片仍展示每份期权 +0.2% 的职业加成，但该数值不再绕过“期权激励”的购买条件。

## 界面与浮窗

- 主界面技能改为紧凑卡片，桌面／平板／手机分别最多显示 12／8／4 个快捷技能；全部技能页同步改为卡片网格。
- 升级和技能浮窗支持鼠标跟随与触摸长按，展示完整效果及当前状态，且不再遮挡按钮点击。

## 回归覆盖

- 覆盖 R1 持有 `1.4488e15` 期权的场景：未购买“期权激励”时设施期权倍率为 ×1；购买前后，单名员工在搬砖收入 1.05 且无其他员工增益时均保持 `0.05355/s`，不再错误达到数十 B/s。
- 覆盖设施期权曲线、三项 Gem Upgrade、GB8、FR7 活动时间、退休重置以及 A0／A4 的不同指数边界。
- 覆盖员工与设施全局倍率隔离、点击技能正常传递，以及设施产出通过 EL2 合法影响搬砖和员工且不重复叠算。
