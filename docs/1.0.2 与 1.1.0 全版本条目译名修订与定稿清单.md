# 《无限工时》1.0.2 与 1.1.0 全版本条目译名修订与定稿清单

> **本地化与世界观对齐原则：**
> 1. **去奇幻翻译腔：** 彻底清除“秘银、夜巫、十字、法阵、奢华/华丽”等西幻与机翻残留，替换为国内大厂黑话、财务术语及 90 年代三线科研所/国企档案用语。
> 2. **三段式暗语植入：** 前期读来是荒诞写实的职场日常，中后期细品则会发现处处指向“1978 穿孔纸带、林总工《周易》罗盘镇机、离岸空壳套利、恒温营养液槽、因果废热与递归死循环”的底层真相。
> 3. **UI 适配与消歧：** 消除不同条目间的重名冲突（如将两处“限量装订”区分开、将“务实冲刺”与“全员冲刺”区分开），并将所有短词控制在 4–7 个汉字以内。

---
