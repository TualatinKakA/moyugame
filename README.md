# 无限工时 · Moyu Game

一款从地球办公室开始的增量放置游戏。点击搬砖、采购设施、加入部门、释放技能，并在退休与投胎中逐步发现：公司的组织规模和你的职阶都没有可确认的上限。

项目使用原创职场题材、剧情和界面；数值与系统组织参考 Realm Grinder，并使用 [G00F's Not a Wiki](https://musicfamily.org/realm/) 进行机制资料核对。

## 当前版本

当前为 **R0～R3 开发版**，核心循环、内容配置、界面和存档结构已经拆分，后续按内容包增量扩展。

已实现的主要基础：

- 点击与设施产出；
- 建筑价格、数量要求和分层升级；
- 部门立场、派系硬币、分层升级和手册；
- 法力、主动技能和部分技能强化；
- 资源置换、数字员工和离线收益；
- 退休结算、期权和 R1～R3 转生增益；
- 档案审计、部分中立／高级部门与 R3 佣兵混编；
- 本地存档、导入导出和版本规范化；
- 桌面与手机端布局。

尚未完成完整成就系统、完整剧情系统、后期研究／血脉／传承／套装，以及实际 Ascension 玩法。具体范围见下方对照文档。

## 本地运行

项目使用原生 HTML、CSS 和 JavaScript 模块，无需安装运行时依赖或执行构建。

```bash
npm run serve
```

也可以直接使用：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:4173/
```

## 操作

- 点击显示器或按空格：搬砖；
- 桌面右侧设施常驻，点击整张设施卡即可按 `1 / 10 / MAX` 采购；
- 左侧集中管理设施、通用和部门升级，仅显示已解锁项目，点击图标查看详情；
- 退休卡固定在工位工作区，显示本次与累计期权；结算不会重建工位 DOM；
- 设施、升级、技能、审计和投胎等资源相关按钮每 200ms 局部同步状态，辅助面板不再每秒整体重绘；
- 技能栏直接显示技能说明、精力消耗和剩余生效时间，精力不足时自动禁用；
- 部门面板：选择立场、加入部门和使用分层升级；
- 审计与统计面板：检索档案、查看剧情和完整统计；
- 更多面板：投胎和存档管理；
- 手机端使用底部抽屉，工位和退休卡保持可见；再次点击导航、点击工位、按 Esc 或系统返回键均可关闭抽屉。

## 测试

```bash
npm test
```

浏览器验收覆盖退休入口与结算、整卡采购、升级解锁显示、工位 DOM 稳定性、抽屉交互、清除进度，以及 320／390／520／768／900／1024／1440px 布局：

```bash
npm install
npx playwright install chromium
npm run test:browser
```

也可通过 `CHROMIUM_PATH` 指定已有 Chromium 可执行文件。Playwright 仅用于开发验收，不是前端运行或构建依赖。

测试覆盖基础经济、建筑与派系升级、法术、挑战、审计、离线收益、退休、转生、佣兵、存档迁移和自动开局模拟。

新增内容或底层修改时，必须同步补充对应测试；公式错误、重复奖励、重置残留和迁移异常不得静默通过。

## 增量开发约定

- 内容使用稳定 ID，界面显示名与数值逻辑分离；
- 新建筑、派系、法术和升级优先添加配置，不修改主循环；
- 新机制放入独立系统模块，并提供测试；
- 存档使用独立 `schemaVersion`，与内容版本分开；
- `contentPacks` 记录已启用内容包；
- `progression` 保存 R／A 进度和升阶历史；
- 统计分为本轮、本次职业、本次升阶和全部历史；
- 派生计算缓存不写入存档；
- 当前 R0～R3 存档会规范化到新结构，旧 Demo 存档不自动迁移；
- 重置前必须明确资源保留关系；
- 后续内容包应复用现有效果类型，不重复实现已有公式；
- 多 Agent 开发遵守文件所有权、统一事件和分支集成约定，不强推覆盖远端更新。

## 存档与离线

游戏使用浏览器 `localStorage` 保存，不会上传服务器。

清除网站数据、使用隐私窗口或更换浏览器可能导致存档丢失。不同设备与浏览器之间的存档不互通。离线收益在重新打开页面时按当前规则补算。
