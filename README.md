# 无限工时 · Moyu Game

以现代职场为题材的增量放置游戏。当前版本将核心循环、内容配置和界面分离，正在按内容包逐步扩展 R0～R3 的建筑、派系、法术、挑战、审计、退位、转生与佣兵系统。

## 本地运行

无需安装运行时依赖或构建。在项目目录运行：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:4173/`。

## 测试

```bash
npm test
```

测试覆盖基础经济、建筑与派系升级、法术、挑战、审计、离线收益、退位、转生、佣兵、存档迁移和自动开局模拟。

## 项目结构

```text
index.html                 页面入口
styles.css                 独立界面与响应式样式
src/
  core/                    数字、状态、存档与迁移
  systems/                 公式、效果与游戏引擎
  content/r0r3/            R0～R3 内容配置
  ui/                      页面渲染与交互
 tests/                    单元、进度和模拟测试
```

## 增量开发约定

- 内容使用稳定 ID，界面显示名与数值逻辑分离；
- 新建筑、派系、法术和升级优先添加配置，不修改主循环；
- 新机制放入独立系统模块，并提供测试；
- 存档使用独立 `schemaVersion`，并分为本轮、本次职业、本次升阶和全部历史统计；
- `contentPacks` 记录已启用内容包，`progression` 保存 R／A 进度和升阶历史；
- 当前 R0～R3 存档会规范化到新结构，旧 Demo 存档不自动迁移；
- 派生计算缓存不写入存档；
- 重置前必须明确资源保留关系；
- 后续内容包应复用现有效果类型，不重复实现已有公式。

## 存档与离线

游戏使用浏览器 `localStorage` 保存，不会上传服务器。清除网站数据、使用隐私窗口或更换浏览器可能导致存档丢失。不同设备与浏览器之间的存档不互通。
